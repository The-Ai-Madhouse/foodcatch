# 0003 – Web app runs locally only (for now)

Status: accepted (2026-11-18)

## Context
Tjek (eTilbudsavis) and Rema 1000 endpoints are unofficial. Republishing their data on a public
website may conflict with their terms and the EU sui generis database right.

## Decision
The repository is public, but the web app is only run locally by the owner. Deployment (e.g.
Vercel) is postponed until data usage is clarified with the sources.
